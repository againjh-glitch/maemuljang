# 매물장 응대 데스크

부동산 사무실에서 손님을 맞을 때 쓰는 웹 프로그램입니다.

- **집 보러 온 손님**: 인사 → 거래·예산 → 집 조건 → 우리 매물 추천 → 대기 손님 등록 (단계마다 응대 멘트 안내)
- **집 내놓는 손님**: 매물장 양식(1~8번) 순서대로 접수 → 저장하면 이 집을 기다리던 손님이 바로 표시
- **매물 검색 / 대기 손님**: 조건별 일치도 점수, 상태(진행중·보류·거래완료) 관리

화면은 이 저장소의 `index.html` 한 파일이고, **매물·손님 데이터는 구글 시트**에 저장됩니다.
전화번호·현관 비밀번호 같은 정보는 깃허브에 올라가지 않습니다.

```
GitHub Pages (index.html)  ──비밀번호──▶  Apps Script 웹앱  ──▶  구글 시트 (매물 / 손님 탭)
```

---

## 처음 설치 (관리자 1회, 약 10분)

### 1. 구글 시트 만들기
1. `매물장_데이터.xlsx` 파일을 구글 드라이브에 올립니다. (이 파일은 깃허브에 올리지 마세요)
2. 드라이브에서 파일을 열고 **파일 → Google Sheets로 저장**을 누릅니다.
3. 새로 생긴 구글 시트를 엽니다. 탭 이름 `매물`, `손님`과 첫 줄 제목은 바꾸지 마세요.

### 2. 비밀번호 정하기 (구글 시트 「설정」 탭)
- `설정` 탭의 **B1**에 사무실 비밀번호, **B2**에 열람 비밀번호를 적습니다. (서로 다르게)
- 바꾸면 바로 적용됩니다. **비밀번호를 잊으면 언제든 이 탭에서 확인**하세요.

### 2-1. Apps Script 붙여넣기
1. 그 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 **고치지 말고 그대로** 붙여넣고 저장합니다.
3. 위쪽 함수 선택 칸에서 `처음실행`을 고르고 **▶ 실행** → 권한 검토 → 고급 → 이동 → 허용.
   실행 로그에 매물·손님 건수와 비밀번호 입력 여부가 나오면 성공입니다.

### 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
2. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
3. **배포** → 구글 계정 권한 허용 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사

> 코드를 나중에 고치면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 반영됩니다.

### 4. 사이트에 주소 넣기
`index.html` 맨 아래쪽의 이 줄에 3번에서 복사한 주소를 넣고 커밋합니다.

```js
var CONFIG={ API_URL:'https://script.google.com/macros/s/…/exec' };
```

이렇게 해 두면 직원들은 사이트의 **설정** 탭에서 **비밀번호만** 입력하면 됩니다.

### 5. GitHub Pages 켜기
저장소 **Settings → Pages → Branch: `main` / `/ (root)` → Save**.
1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 열립니다.

## 직원 사용법
1. 사이트 주소를 즐겨찾기 합니다.
2. 처음 한 번 **설정** 탭에서 사무실 비밀번호를 입력합니다. (그 컴퓨터·브라우저에 기억됨)
3. 오른쪽 위에 `공유 매물장 연결됨`이 보이면 끝. 1분마다, 그리고 화면으로 돌아올 때마다 새로 불러옵니다.

### 민감 정보 (연락처 · 현관 비밀번호 · 원문)
| | 사무실 비밀번호 | 열람 비밀번호 |
|---|---|---|
| 매물 보기·검색·매칭, 손님 응대 | O | O |
| 새 매물·손님 접수 (연락처 입력 포함) | O | O |
| 집주인·손님 **연락처**, **현관 비밀번호**, 내놓은 분, 원문 보기 | X (🔒 표시) | O |
| 기존 매물의 연락처·현관 비밀번호 수정, 삭제 | X | O |

- 사무실 비밀번호만으로는 이 정보가 **서버에서 아예 전송되지 않습니다** (화면에서만 가리는 방식이 아님).
- 매물 상세 화면의 🔒 상자나 **설정 → 2단계**에 열람 비밀번호를 넣으면 열립니다.
- 열람은 브라우저를 닫거나 30분 동안 쓰지 않으면 자동으로 다시 잠깁니다. ("이 컴퓨터에서 기억"을 체크하면 유지)
- 현관 비밀번호는 매물 접수 4단계의 **"집 보는 방법 · 현관 비밀번호"** 칸에 적으면 됩니다. 텔레그램을 다시 뒤질 필요가 없도록 기존 매물의 비밀번호도 이 칸에 옮겨 두었습니다.

## 팀원이 함께 수정하기
- **데이터(매물·손님)**: 사이트에서 접수·수정합니다. (구글 시트는 관리자가 직접 고칠 때만)
  - 거래조건 형식: `매매 45000 / 전세 38000 / 월세 3000/60` (만원, `4억5천`도 가능)
  - 엘베·주차·반려동물: `O` / `X` / 빈칸
- **화면·기능(코드)**: 깃허브 저장소 **Settings → Collaborators**에서 팀원을 초대하면 `index.html`을 함께 고칠 수 있습니다.
  깃허브 웹에서 파일을 열고 연필 아이콘으로 고친 뒤 커밋하면 1~2분 뒤 사이트에 반영됩니다.

## 보안 메모
- 저장소가 공개여도 데이터는 구글 시트에만 있고, 비밀번호 없이는 읽을 수 없습니다.
- 비밀번호를 바꾸려면 구글 시트 `설정` 탭의 B1/B2만 고치면 됩니다. (재배포 필요 없음)
- 구글 시트 파일 자체에는 모든 정보가 있으니 **관리자만** 볼 수 있게 두세요. 직원은 사이트로만 씁니다.
- 퇴사자가 생기면 비밀번호를 바꾸는 것을 권장합니다.
- 비밀번호는 깃허브 어디에도 적지 마세요. 구글 시트 `설정` 탭에만 둡니다.
